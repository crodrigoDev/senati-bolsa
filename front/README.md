# Frontend - SENATI Bolsa 🚀

Este es el cliente del sistema SENATI Bolsa, desarrollado con **Next.js 16**, **TailwindCSS** y **Shadcn/UI**.

## 🛠️ Instalación Rápida

Para instalar todas las dependencias necesarias (incluyendo `recharts`, `dnd-kit`, `react-table`, etc.), ejecuta el siguiente comando en esta carpeta:

```bash
npm install
```

## 🏃‍♂️ Ejecución

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en: **[http://localhost:3000](http://localhost:3000)**.

---

### 📦 Librerías Principales Instaladas
- **UI:** Shadcn/UI, Lucide React, TailwindCSS.
- **Gráficos:** Recharts.
- **Tablas:** TanStack React Table.
- **Drag & Drop:** DND Kit.
- **Formularios:** React Hook Form + Zod.
